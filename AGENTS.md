# AGENTS Rules (Project-Local)

## LLM Development Rules

1. Do not hardcode behavior based on user-input keywords, regex branches, or fixed phrase matching.
2. Do not hardcode assistant reply text for dialog/clarification/follow-up messages.
3. Parameter sufficiency and follow-up questions must be decided/generated by the LLM itself.
4. Allowed backend logic is only generic plumbing:
   - tool registration and invocation
   - schema/type validation that is tool-agnostic
   - transport/error handling (JSON parsing, API/network exceptions, retries/timeouts)
5. If defaults are needed, the LLM must explicitly ask user confirmation first; do not auto-apply defaults with handwritten user-intent logic.

## Scope

These rules apply to all code in this repository, especially `server/llm_*` and any future LLM agent/router modules.
